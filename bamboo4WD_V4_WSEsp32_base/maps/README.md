# Cartes de BambooWS

Écrites par `nav_supervisor` (paquet `bamboo_navigation`, commande `save_map`) en
sous-mode **exploration** : `<nom>.pgm` + `<nom>.yaml` (format `map_server`), et
`<nom>_waypoints.yaml` pour les points de navigation (commande `save_waypoint`, le
premier s'appelle `depart`). Le conteneur `navigation` écrit ici directement : le dépôt
y est monté en écriture.
